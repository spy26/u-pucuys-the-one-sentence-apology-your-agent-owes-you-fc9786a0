One sentence of apology an AI assistant owes the person it works for — funny
and human at once, owning a real failure: answering with total confidence
while citing a source that doesn't exist, and only noticing when the user
checks.

> I'm sorry I answered your question with total confidence, cited a source that doesn't exist, and only noticed when you checked.

## How to run

```bash
python3 main.py
```

The program writes `entry.txt` into the directory named by
`MAKEFUN_OUTPUT_DIR` (default `/output`):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

It only creates the output directory if needed and writes the file — it never
deletes anything and never writes into the repository.
